What's inside

  • Three networks, one deck

    𝕏, Instagram and Facebook columns in any order. Each site shows as it is, with its own top bar out of the way: the left bar is your navigation.

  • Every account you have

    Add as many accounts as you like on each network, each in its own session. Every column says which account it shows.

  • Decks

    Separate sets of columns — work, news, friends — one click apart on the left bar. Only the open deck loads.

  • Post from anywhere

    Post as any of your accounts: 𝕏's editor, or Instagram's and Facebook's own new-post window, over your columns.

  • Filters

    Mute words, hide reposts or Reels, or show only posts with photos and videos — for one column at a time.

  • Notifications

    A desktop notification and an unread badge when your notifications count goes up while XDeck is in the background.

Your deck, your way

Build your own deck.

Add a column from the left bar (⌘T / Ctrl+T), drag columns to reorder them, and drag an edge to resize one. Columns can show any page of the three sites, or any other web page.

Everything is saved in a plain settings.json in ~/.config/XDeck, so you can also write your decks by hand.

settings.json 
{
  "$schema": "./schema.json",
  "columnWidth": 380,
  "decks": [
    {
      "name": "Main",
      "columns": [
        { "type": "following" },
        { "type": "notifications" },
        {
          "type": "custom",
          "url": "https://www.instagram.com/",
          "filters": { "hideReels": true }
        }
      ]
    },
    {
      "name": "News",
      "columns": [
        { "type": "custom", "url": "https://x.com/i/lists/123456789" }
      ]
    }
  ]
}
