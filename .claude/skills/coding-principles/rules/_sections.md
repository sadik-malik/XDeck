# Sections

This file defines all sections, their ordering, impact levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Simplicity (simplicity)

**Impact:** HIGH  
**Description:** KISS and YAGNI: no more structure than the current problem requires. Ranks right after correctness.

## 2. Duplication (dry)

**Impact:** MEDIUM  
**Description:** DRY (Don't Repeat Yourself): one authoritative representation per piece of knowledge, not per text match.

## 3. SOLID (solid)

**Impact:** LOW-MEDIUM  
**Description:** At module/class/function boundaries — how responsibilities are split, not a mandate for factories/DI everywhere.

## 4. Design Heuristics (design)

**Impact:** LOW-MEDIUM  
**Description:** Layering, coupling, and error-handling guidelines.
