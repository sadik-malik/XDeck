# Sections

This file defines all sections, their ordering, impact levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Context (context)

**Impact:** CRITICAL  
**Description:** The file's existing conventions and any configured formatter override every other spacing rule.

## 2. Blank Lines (blank)

**Impact:** HIGH  
**Description:** One blank line = one conceptual boundary. Missing or misplaced blanks hide the structure of the code.

## 3. Declarations (decl)

**Impact:** MEDIUM  
**Description:** Spacing between functions, classes, methods, and fields, including per-language conventions.

## 4. Horizontal Spacing (horizontal)

**Impact:** LOW  
**Description:** Spaces within a line and consistent indentation.
